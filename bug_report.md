# Дефект PIN-001: генератор PIN не использует цифру 9

- Модуль: initial_with_bug/password_generator.py.
- Функция: generate_pin.
- Первоначальный статус: Open.
- Серьёзность: Minor — PIN создаётся, но допустимый алфавит неполон.
- Ожидаемый результат: каждая позиция PIN выбирается из 0123456789; цифра 9 доступна.
- Фактический результат: символы выбираются из 012345678; получить цифру 9 невозможно.

## Воспроизведение

1. Загрузить исходную версию модуля.
2. В тесте подменить secrets.choice функцией, возвращающей последний символ переданного алфавита.
3. Вызвать generate_pin(1).
4. Получить "8" вместо ожидаемого "9".

Обнаруживший тест: test_pin_can_generate_both_digit_endpoints. Дополнительно test_pin_keeps_leading_zero проверяет, что в secrets.choice передаётся полный алфавит цифр.

## Исправление и повторная проверка

В основной версии password_generator.py алфавит 012345678 заменён на string.digits. На исправленной версии весь набор из 18 тестов проходит, включая оба теста дефекта. Итоговый статус: Closed.
